      About These Data

      How the dashboard is updated

      1. 1

        NHDES sends the data. One Excel workbook with every funded project, up to twice a year.

      2. 2

        It is checked. Automated checks catch missing amounts, date errors, duplicate projects and misspelled categories.

      3. 3

        Projects are mapped. Each project is placed in its town or village until NHDES provides street addresses.

      4. 4

        The dashboard updates. New figures appear everywhere at once; nothing else on the page changes.

      The dollars NHDES has formally agreed to provide to a project

      Comma-separated values, a spreadsheet file you can download
